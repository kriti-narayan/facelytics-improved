# Facelytics


Facial Recognition App using Python + Eel.js
A sleek, modern web interface for real-time facial recognition using Python, OpenCV, and Eel.js. This app captures webcam video, processes each frame using Python's face recognition libraries, and displays results in a stylish front-end.

Features
🔍 Real-time facial recognition via webcam

🖥️ Beautiful glassmorphism-style UI (HTML/CSS/JS)

🔄 Seamless Python ↔ JavaScript interaction using Eel

📸 Frame-by-frame analysis using OpenCV

🧪 Easy to extend with face labeling, authentication, or alerts
